# Página final de Aplicaciones Web - ApexDroid

Base inicial para construir el sitio acordado por el equipo. El objetivo, las pantallas y el contenido deben corresponder al diseño ya definido por el equipo.

## Estructura

- `index.html`: página de inicio.
- `pages/`: páginas adicionales.
- `css/styles.css`: estilos compartidos.
- `js/main.js`: interacciones compartidas, si se requieren.
- `assets/`: imágenes e iconos.
- `docs/`: acuerdos, requisitos y reparto de archivos.

## Acuerdos de equipo

1. Mantengan `main` como la versión integrada y funcional.
2. Cada integrante trabaja en una rama para su pantalla o tarea.
3. Antes de editar un archivo compartido, coordinen quién lo modifica.
4. Integren avances pequeños y revisen enlaces y rutas en conjunto.
5. Consulten `docs/pantallas-y-requisitos.md` para conocer el reparto.

Esta estructura es un punto de partida; no reemplaza el diseño ni define contenido que el equipo no haya acordado.
